# Órbita — Quiz de exploración espacial

Órbita es un cuestionario interactivo en español sobre exploración espacial. Incluye preguntas de opción múltiple, seguimiento de puntuación y progreso, explicaciones y un diseño adaptable con tema claro y oscuro.

## Ejecutar localmente

No se necesita instalar dependencias ni iniciar un servidor. Abre `index.html` directamente en un navegador (por ejemplo, haciendo doble clic en el archivo).

## Publicación

El sitio se publica en GitHub Pages mediante GitHub Actions al actualizar la rama `main`. El flujo de trabajo publica `index.html` tal cual; no hace falta compilarlo. La URL es [https://karenariz.github.io/space-quiz/](https://karenariz.github.io/space-quiz/).
